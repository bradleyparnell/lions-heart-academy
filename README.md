# Lion’s Heart Academy — Homepage Concept

A polished, responsive homepage concept created to demonstrate the strategic and visual direction for Lion’s Heart Academy in León, Guanajuato.

## Direction

- StoryBrand-led messaging: the parent and student are the hero; Lion’s Heart is the guide
- Dark English green, black, white, and gray palette
- Restrained leather-inspired texture and detailing
- Clear admissions conversion path
- Responsive desktop and mobile presentation
- Preschool retained as a planned/returning program

## Preview locally

Open `index.html` in a modern browser. No build process or dependencies are required.

## Important

This is a design concept. Final copy, school claims, contact information, credentials, program status, photography, and bilingual content require approval before production launch.
